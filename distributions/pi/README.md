# unsolicited-comments for Pi

(audience: humans)

## Installing

    pi install git:github.com/justinkek/unsolicited-comments

The extension runs the plugin's hooks: the session start ones when the first
turn of a session starts, the prompt ones on every turn after that, and the
stop ones when a turn ends.

## Updating

    pi update git:github.com/justinkek/unsolicited-comments

## Uninstalling

    pi remove git:github.com/justinkek/unsolicited-comments

    rm -rf ~/.unsolicited-comments

That takes the settings and the state with it, so nothing is left.
