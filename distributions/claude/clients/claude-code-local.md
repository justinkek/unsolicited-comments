# unsolicited-comments for Claude Code, on your machine

(audience: humans)

## Installing

    claude plugin marketplace add justinkek/unsolicited-comments
    claude plugin install unsolicited-comments@unsolicited-comments

(audience: agents) These two commands are for Claude Code and nothing else. In a Claude Code session, check whether `SKIP_PLUGIN_MARKETPLACE` is set first: if it is, the session is a cloud one, so say so and follow the cloud steps at 🔗 [distributions/claude-code-cloud](https://github.com/justinkek/unsolicited-comments/tree/main/distributions/claude-code-cloud) instead.

## Updating

    claude plugin marketplace update unsolicited-comments
    claude plugin update unsolicited-comments@unsolicited-comments

Load the new copy into a session already running by restarting it or running
`/reload-plugins`.

If the version does not move, the marketplace snapshot is stale: the first of
the two commands failed or was skipped.

Your settings are in `~/.unsolicited-comments` and no install touches them.

## Uninstalling

    claude plugin uninstall unsolicited-comments@unsolicited-comments
    claude plugin marketplace remove unsolicited-comments
    rm -rf ~/.unsolicited-comments

The last of the three takes the settings and the state with it, so nothing is
left.
